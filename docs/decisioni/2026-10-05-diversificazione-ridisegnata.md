# 2026-10-05 — Diversificazione (Diversification) tab redesigned (mobile first)

- **Map**: exposure by area is a dot map (land masses generated from Natural Earth, `scripts/generate-world-dot-map.mjs`). The data are the app's 7 areas, not countries: with a global ETF a few large blocks light up, so the map is an at-a-glance view and the list below remains the source of the numbers. Tapping a row highlights it on the map.
- **Sectors**: each sector has an icon (`sector-icons.ts`) and the same sorted bars as the areas.
- **"Da dove vengono i dati"** ("Where the data comes from") and **Allocazione obiettivo** (target allocation) open only on request (`Disclosure` / "Dettaglio" button).
- **Overlaps in words**: judgements such as "Quasi lo stesso investimento" ("Almost the same investment") and "Si muovono quasi sempre insieme" ("They almost always move together") instead of percentages and matrix (thresholds in `lib/investments/plain-labels.ts`); the full matrix remains in "Tabella completa". Correlations are grouped into "families" of positions that move together (threshold 0.75), with the pairs in "Tutte le coppie".
- Postponed: per-country map (it would need the per-country breakdown from the sources), landing/screenshots (regenerated by the daily workflow).
