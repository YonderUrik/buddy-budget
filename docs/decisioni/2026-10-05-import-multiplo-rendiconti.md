Data: 2026-10-05

Richiesta la selezione contemporanea di più file dopo il reset. Coda IBKR/DEGIRO con lettura preventiva, limiti espliciti e ordine cronologico per conto (IBKR prima di DEGIRO). Conservati controllo strumenti, anteprima e conferma per ogni file; import indipendenti e idempotenti, avanzamento visibile, errore senza avanzamento.
