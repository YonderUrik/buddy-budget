# Import: manual instruments already present are also linked to a listing (2026-10-08)

After a successful import (CSV and statement), every manual instrument with an ISIN of the user involved is linked to the first verified listing (OpenFIGI + Yahoo, in the instrument's currency), as with «Cerca la quotazione» ("Find the listing"); the price history restarts from its first operation. Previously, securities recognized as «già tra i tuoi strumenti» ("already among your instruments") stayed manual. If there is no listing or the sources do not respond nothing changes and the import does not fail. The row in the «Strumenti» (Instruments) step says so. Landing impact: none. Log: `instrument.quotation.linked` from the import as well.
