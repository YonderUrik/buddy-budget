# 2026-10-09 — Sidebar: optional modules and bottom bar on mobile

- The desktop sidebar stays as it is (items, summary, user) and gains two modules: **Prossime scadenze** ("Upcoming deadlines": loan instalments and bank connections to renew, max 4) and **Obiettivo FIRE** ("FIRE goal": progress bar, how much is left, estimated years). Order: Oggi, Scadenze, FIRE, Portafoglio, Watchlist: the short modules sit above the long ones, so they stay visible even on short laptops.
- The FIRE goal uses `buildAnalyticsBase` + `resolvePlan` from Analitiche, hence the same data and assumptions (same figures); it is the heaviest query of the sidebar (`/api/sidebar/fire`), so a 1-hour client-side cache and no request if the module is off.
- On mobile (< 768px) a **bottom bar** (Panoramica, Liquidità with badge, Investimenti, Debiti, «Altro» — "More") replaces the hamburger; «Altro» opens the full drawer (Pensione, Analitiche, summary, deadlines, profile). The sync panel rises above the bar via `--bottom-nav-offset`.
- **Everything is configurable** from Impostazioni → «Barra laterale» ("Sidebar"): each module (also Patrimonio, Portafoglio, Watchlist) and the bottom bar can be turned on/off. Choice **per device in localStorage** (like the theme and «previdenza nel totale», "pension in the total"), not per account: no migration; if it is needed on all devices it will move to a user column.
- Postponed: reorderable modules, other modules (month's budget, triggered price alerts), customizable bottom-bar items, deadlines from other sources (bollo, stamp duty; taxes).
