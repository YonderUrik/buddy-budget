# Step-by-step forms: one question at a time (2026-10-10)

- **Decision**: long forms become linear paths, one step at a time, with «Passo X di N» ("Step X of N"), «Indietro» ("Back") always available and focus on the first field of the step. Shared components in `components/domain/shared/step-flow.tsx` (`useStepFlow`, `StepProgress`, `StepStage`, `StepHeading`, `StepActions`); transition with `motion` (already adopted), springs from `lib/motion/springs`, fade only with reduced motion.
- **All together in the same PR** (Daniele's request): onboarding (currency, confirmations), new manual account (name and type, balance), new transaction (amount, description and category, account and date), new investment operation (type and instrument, date and amounts, costs if any), investment import (first step with the file only, broker guide on request), personal CSV import (from where, file, consent), new debt (how it starts, name, data, fees and preview), new pension fund (name, enrolment). «Segna pagata» ("Mark as paid"): linking the transaction hidden under «facoltativo» ("optional").
- **Unchanged**: editing an operation (one screen, already familiar to whoever opens it), report form (already three elements), other Debiti windows (instalment, early repayment, event: few prefilled fields).
- **Observability**: Umami events `form_step_completed` and `form_step_back` (`flow`, `step`); no new server-side log or metric.
- **Standard dialog** (same PR): `FormDialogContent` (`components/domain/shared/form-dialog.tsx`) is the container of every dialog with a form: full screen on phone, centred with fixed width from `sm` up (`size="wide"` only for imports), «Chiudi» ("Close") always present, internal scrolling. 17 dialogs migrated; removed Liquidità's `dialog-layout.ts` and `dialog-close-button.tsx`. Excluded the informational dialogs of Analitiche (guide and scenarios).
- **Less information**: the new transaction goes down to two steps, with date and account prefilled (today, first account) behind «Cambia» ("Change").
