# 2026-10-11 — Simpler default categories and «Categorie» ("Categories") step in onboarding

- Default categories go from 33 to 23 (plus «Da categorizzare», "To categorize"): merged those that cannot be told apart from bank transactions (Bollette + Internet, Trasporti + Manutenzione auto, Abbigliamento + Shopping & Tecnologia, Sport + Cura personale, Fondo emergenza + Risparmio per obiettivi), shorter names, new «Contanti» ("Cash") for withdrawals. Full proposal: `/mnt/project-files/categorie-default/proposta.md` (thread «Categorie di default e onboarding»), approved by Daniele.
- Five optional ones (Figli & Scuola, Animali, Pensione integrativa, Imprevisti, Lavoro autonomo — "Children & School, Pets, Supplementary pension, Unexpected expenses, Self-employment") are not created automatically: they are switched on in the onboarding step.
- Each category has a short description (column `categories.description`, migration 0031, with a backfill for the names of the previous defaults): the user sees it and the assistant (Jev) receives it as guidance for the choice. It is edited in the category detail.
- «Categorie» step after the currency: labels by group and «Continua con queste» ("Continue with these"); «Personalizza» ("Customize") opens a sheet (from the bottom on phone) to turn off, rename or add. Categories are created at sign-up: onboarding sends only the changed choices, applied in a transaction and only if the user has no transactions; an error does not block onboarding.
- Existing users keep their categories; `LEGACY_CATEGORY_NAMES` updated only for the manual reset.
- Postponed: changing icon and colour in the step (done in Categorie), suggesting categories based on the linked bank.
