# Transfers between own accounts and personal instructions for categorization

- Added the neutral type `trasferimento` (transfer) and the category «Trasferimenti tra i miei conti» ("Transfers between my accounts"), for both signs. Assignment, rules and edits keep `excludedAmount = amount`: actual income/expenses, cash flow and budgets do not count it, while the original transaction stays visible. Recategorizing restores the counting; the counterpart is not created automatically.
- New section in the board and in the selector, with neutral amounts and «Escluso dai conteggi» ("Excluded from totals"). Transfers are not offered to the AI: recognizing account ownership requires information other than the merchant name.
- Impostazioni → Notifiche e assistente (Settings → Notifications and assistant): personal instructions (maximum 2,000 characters), included in the Jev context only with the assistant active. Changing them invalidates only the user's own pending proposals; confirmed ones and the transactions stay unchanged. In-flight responses with previous instructions are discarded. Instructions included in the data export, never in logs/events.
- Migration `0033_categorizzazione_giroconti_istruzioni` verified on an isolated local Postgres; to be applied to the target environment before the code. No change to the production DB in this PR.
- Observability: log event `categorization.ai.instructions.updated`, Umami event `ai_categorization_instructions_saved`; reuse of the categorization, transaction and AI request signals. No new job/alert. For the release, check these events, the existing AI metrics and a pair of transfers that does not alter the monthly summary.
- Performance: categories and transactions are updated in the same transaction; no new UI dependency. AI batch reduced to 5 in the same PR. Automatic retries and matching of the two sides of a transfer remain postponed.
- Landing: catalog updated and synced; real screenshots with demo data. Seed aligned with the «Altre entrate» ("Other income") category and enriched with both sides of a transfer.
