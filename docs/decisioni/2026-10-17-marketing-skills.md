# Marketing skills in the repository (2026-10-17)

Daniele asked to try the marketing skills from `coreyhaines31/marketingskills` (MIT) on BuddyBudget: conversion, copy, SEO/discovery and ads, then a brainstorm on Instagram. 27 of the 50 skills are copied into `.claude/skills/` (text only, no CLI tools or evals; list and upstream commit in `.claude/skills/MARKETINGSKILLS.md`), so every future session has them. The B2B and outbound ones are left out to keep the skill list short.

`.agents/product-marketing.md` is the shared product context that all these skills read first (audience, voice, objections, what never to say, ads constraints, learnings). It is updated in the same PR when positioning, pricing or a tested lesson changes.

The audits and the Instagram brainstorm made with them are working documents for Daniele, not repo docs; copy changes for the landing go through the thread that owns `landing/`.
