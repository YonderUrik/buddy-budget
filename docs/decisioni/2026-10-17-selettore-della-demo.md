# Demo chooser: one menu, demos grouped by country (2026-10-17)

The public demo footer showed two country buttons and a language link, each with a flag, so the Italian flag appeared
twice («Italia», «Italiano») and the language list greyed out the languages of the other country. Daniele found the
switch unclear. The footer now has one menu like the landing's language menu (globe, «Italia · Italiano», chevron)
that lists every demo grouped by country, with what the country changes («Con tasse e regole italiane») and each
language written in itself; a choice opens that demo account on the same page. Adding a country or language only needs
`COUNTRY_LANGUAGES`.
