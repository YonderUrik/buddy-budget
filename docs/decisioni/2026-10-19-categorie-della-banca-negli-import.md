# Bank categories in imported files, applied without asking (2026-10-19)

Daniele asked that when an imported account file carries the bank's own category column, transactions take the matching BuddyBudget category without the user confirming it.
The personal CSV import now keeps that label on each cash row (`transactions.bank_category`, encrypted; migration 0045), read by the AI parser or, for parsers saved before, straight from the file's header (`Categoria`, `Category`, `Kategorie`, `Moneymap`, optional subcategory). `confirmImport` maps it with no AI: what the user taught by correcting at least two rows with the same label, then a category with the same name, then a hand-kept it/en/de dictionary pointing at default category keys. A mapped row gets `categorySource = banca`, lists in «Messe dall'app» with the «Banca» origin and stays editable; a correction counts as one and teaches later imports.
Choices: the bank's category is applied **whatever the «Lascia che l'app scelga quando è quasi certa» setting** (it is data from the file, not a guess), but user rules win, generic labels («Altro», «Other») and transfer categories never map, the amount's direction is enforced, and Ricategorizza changes these rows only through a rule. Works on self-hosted installs too (the mapping needs no key; the import itself still needs OpenRouter).
This widens what is applied without the user: the Terms still say proposals never apply on their own, to be aligned at the professional legal review together with the 90% threshold. Deferred: bank categories from GoCardless (not provided in a usable form), a dictionary learned across users.

Same PR, after Daniele noticed that nobody looks at Categorizza: «Messe dall'app» stops looking like work to confirm. Those categories were already applied; only the list made them look pending. It is now the last 30 days of what the app set, with no counter, no «Va tutto bene» (route `/api/transactions/auto-categorized/seen` and event `categorization_auto_reviewed` removed) and Categorizza opening on «Da decidere». `auth_user.auto_categorized_seen_at` stays unused, to be dropped in a later migration so pods of the previous release keep working during the rollout.
