# Zero data retention on every AI request (2026-10-19)

**Decision**: every OpenRouter request (category suggestions, «Chiedi all'AI», CSV parser writing and re-analysis) sends `OPENROUTER_PRIVACY` (`provider: { zdr: true, data_collection: "deny" }`, `lib/llm/openrouter.ts`), and Daniele turned on Zero Data Retention for all models in the hosted OpenRouter account. OpenRouter combines the two with OR, so either is enough; a model with no ZDR endpoint gets the request rejected, never routed to a provider that keeps data. A test fails if a file calling OpenRouter does not send the constant.
**Said to users**: a new «Zero data retention per l'intelligenza artificiale» section in the Privacy policy (`#zero-data-retention`, Italian and English), a line in the Terms, Settings («Dove l'app usa l'AI» with a link to that section on hosted installs, the assistant switch hint), the onboarding assistant step and the /sicurezza AI block (with the OpenRouter ZDR doc as source). `LEGAL_VERSION` 2026-10-20: everyone re-accepts once.
**Limits stated, not hidden**: ZDR covers the model providers OpenRouter routes to (inference only, not plugins or tools, which we don't use); OpenRouter keeps usage metadata (model, tokens, cost); we keep the result and technical logs without request content for 30 days. Self-hosters keep the per-request guarantee, the account setting is theirs.
**Owner check**: prompt logging must stay off in the OpenRouter account (Settings → Privacy), since the Privacy policy says OpenRouter keeps no request text.
