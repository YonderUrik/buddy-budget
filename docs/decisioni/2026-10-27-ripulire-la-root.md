# Cleaner repository root (2026-10-27)

Daniele asked for a root with fewer configuration files. Moved where the tool accepts a path: `CONTRIBUTING.md`, `SECURITY.md` and `CODE_OF_CONDUCT.md` to `.github/` (GitHub still finds them there), `ACCESSIBILITY.md` to `docs/accessibility.md`, release-please config and manifest to `.github/` (paths in `ci.yml`), `drizzle.config.ts` to `lib/db/` (`pnpm db:generate` passes `--config`), `vitest.setup.ts` to `lib/testing/`, `.env.selfhost.example` and `docker-compose.build.yml` to `deploy/selfhost/` (`env.example`, `compose.build.yml`; paths in an override file resolve from the first compose file, so `context: .` is still the root), `.agents/product-marketing.md` to `.claude/` (the marketing skills already read it there). Removed, because nothing used them: `bun.lock` (pnpm is the package manager), `vercel.json` (Vercel is off), `.pnpmfile.cjs` (no-op hooks) and `.npmrc` (default values only).

Stay at the root because their tool looks only there: `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`, `tsconfig.json`, `next.config.ts`, `postcss.config.mjs`, `eslint.config.mjs`, `vitest.config.ts` (editor integrations), `components.json` (shadcn), `proxy.ts` and `instrumentation.ts` (Next.js), `Dockerfile`/`.dockerignore` (CI builds with the root as context), `docker-compose.yml` (self-hosters run `docker compose up -d`), `.mcp.json` and `CLAUDE.md` (Claude Code), `.gitignore`/`.gitattributes`, `.codegraph/`. Kept by convention: README, LICENSE, NOTICE (AGPL), CHANGELOG (release-please), ROADMAP, `.env.local.example`, and `proxy.test.ts` beside `proxy.ts` (tests sit next to their source).
