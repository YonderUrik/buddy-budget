# 2026-10-27 — Manual account balances follow the transactions typed by hand

Reported by a user and reproduced by Daniele: adding a transaction to a manual account left its balance unchanged. Root cause: `POST /api/transactions` only inserted the row, and `PATCH`/`DELETE /api/transactions/[id]` never touched the account either; manual accounts were designed as "the balance is whatever you type", which nobody expects once transactions can be added to them.

Now a transaction typed by hand moves its account's balance in the same database transaction: added (+amount, so an expense lowers it), amount edited (+difference), deleted (−amount). One helper, `moveAccountBalance` in `lib/transactions/account-balance.ts`, with SQL `balance + delta` (no lost updates) and a `source = manuale` guard, so bank-linked accounts keep the bank's balance. The same call fixes import accounts, whose single rows edited or deleted by hand used to leave the balance out of step with the ledger history. The client invalidates accounts, cash history, the sidebar total, goals and the month's budget after every transaction change.

Existing balances (Daniele's choice among automatic correction, asking each user, or leaving it to them): migration 0051 adds once, at release, to each manual account the hand-typed transactions (`source = manuale`, no `external_id`) created after the account was last edited (balance, name or icon). Earlier ones may already be in a balance the user corrected by hand, so they are left out; an account renamed after its transactions stays under-corrected, never counted twice. Bank-linked, file-import and broker cash accounts and sample-data accounts are skipped. The migrator prints `manual_balance_backfill: N accounts corrected`. Transactions added between the migration (ArgoCD PreSync) and the rollout of the new code are not counted.

Still out: manual accounts have no reconstructed past (a back-dated transaction shows on the day it is added; living doc `docs/architecture/net-worth.md` §4.1 and §5). Texts of «Conto manuale» in «Nuovo conto», the feature catalog and the login sheet now say the balance follows the transactions.
