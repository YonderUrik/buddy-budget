# 2026-11-03 — «Cerca» does the maths: the AI reads the question, the server computes it

Daniele asked for «Cerca» to answer real questions about money (averages, how often, the biggest, splits, comparisons) instead of the fixed totals of #517. «Chiedi all'AI» now also fills one closed analysis query (`AnalysisQuery`: measure, direction, filters, period, split, order, limit, comparison), checked by zod and cleaned by `cleanAnalysis`; the model never writes SQL, never sees a row or a figure, and its words are matched to the user's own categories and accounts by the server afterwards. A pure engine (`lib/search/analysis-engine.ts`) computes the answer on the user's rows: plain columns over any period without words, decryption only within the existing 24-month / 6,000-movement window when words or a split by merchant need the text. The card shows the figure, how it was made, the split or bars, and «Cosa ho capito» as chips, so a wrong reading is visible; every row opens Movimenti on that part.

When to ask (decision card in the thread, recommended and implemented): the AI is called on Enter or a tap, never automatically while typing; for a question the AI row comes first («Chiedi all'AI di fare i conti»), so Enter asks. The existing consent, ZDR, cache and per-user/service limits are unchanged, and so are Privacy and Terms (they already describe «Chiedi all'AI» reading the sentence only, no `LEGAL_VERSION` bump).

Signals: log `search.analysis.completed`, metrics `buddybudget_search_analyses_total{measure,group_by,outcome}` and `buddybudget_search_analysis_duration_seconds` (panel in the infra repo), Umami `search_analysis_shown`. No migration. Living doc §4.19 of `docs/architecture/overview.md`. Deferred: investments, debts and pension in analyses, percentiles and trends, links to Movimenti for periods that are not one calendar month or year.
