# Investimenti › Performance opens on the year to date (2026-11-03)

Daniele found Performance slow to open on «Max», the default since 2026-10-31, and asked for year to date instead. The page now opens on «YTD» (`PERFORMANCE_DEFAULT_PERIOD` in `lib/investments/chart-period.ts`); «Max» is still one tap away.
Why «Max» was slow: the day-by-day portfolio walk (`computeDailyPortfolioValues`, every day × every position) ran five times over the same days for one view (chart, returns, risk, period gain, cost impact), and again on every pointer move over the chart, because the hover recomputed the returns from the first operation. The walk now keeps its last results per transactions array and serves a range inside them as a slice, and the hover reuses the view's own inputs. On the demo data repeated over six years (27k prices, 342 operations, Node): building the view on «Max» 140 → 98 ms, each hover 41 → 8 ms; on a phone the same work is a few times slower, so the gap was visible. The data request is unchanged: Performance still loads the whole history, which returns need from the first operation.
No migration, no change to figures, no impact on the landing (it does not name the starting period). No new signal: this is a client-side calculation.
