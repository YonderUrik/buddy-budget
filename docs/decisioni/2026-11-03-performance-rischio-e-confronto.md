# 2026-11-03 — Performance: risk on a half dial, the index comparison as a scoreboard

Daniele found the «Confronta con un indice» dialog hard to read (pill-shaped buttons on three-line boxes, no logos) and the Performance risk and comparison blocks wordy. Among two proposals captured in the real app he chose: the dialog as rows (A), each index with its provider's logo, area, companies, countries and ETF; the risk card A, renamed «Rischio», with a half dial and plain labels («Calo più forte», «Rendimento per rischio», «Legame con l'indice»), fall chart still collapsible; the comparison as a scoreboard (B): one headline with who did better and by how much, then «Tu» and the index side by side. The short index name replaces the ETF name across the page; the security page uses the same dial. Index logos are served only for the four suggestions through the existing Logo.dev cache (`/api/benchmarks/[id]/logo`). Umami `investment_benchmark_chosen` (which index, `other`, `none`). No migration. Living doc §4.8 and §4.10 of `docs/architecture/investments.md`. Screens in the project files (`performance-rischio-confronto/`).
