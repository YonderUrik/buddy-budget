# better-auth authentication — Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement complete authentication (magic link + Google OAuth) with better-auth, replace the stub `users` table with the 4 `auth_*` tables, and create the `/login` and `/onboarding` pages with the route-protection middleware.

**Architecture:** better-auth manages the session lifecycle through 4 Postgres tables (`auth_user`, `auth_session`, `auth_account`, `auth_verification`). A Next.js middleware with the Node.js runtime protects all routes, redirecting unauthenticated users to `/login` and new users (onboarding not completed) to `/onboarding`. Auth pages live in the `(auth)/` route group without AppShell; app pages live in the `(app)/` route group with AppShell. When a new user is created, a `databaseHooks.user.create.after` automatically seeds the default categories.

**Tech Stack:** `better-auth` (magic link plugin + Google OAuth), `resend` (email sending), Drizzle ORM (better-auth adapter + query builder), Next.js App Router (route groups, Node.js runtime middleware), React (controlled forms, `useRouter`)

## Global Constraints

- Package manager: `pnpm` (not npm or yarn)
- All user-visible strings: in Italian
- No hardcoded hex colors: use the Tailwind tokens (`bg-background`, `text-foreground`, `text-text-2`, `text-text-3`, `bg-primary`, etc.)
- `user_id` in the domain tables: type `text` (not `uuid`), to align with the `text` PK of `auth_user`
- Drizzle schema for the auth tables in `lib/db/schema/auth.ts`; `lib/db/schema/users.ts` is deleted
- No circular imports: `lib/auth/index.ts` → `lib/db/client.ts` + `lib/db/schema/*`; never the other way round
- `drizzle-kit push` to apply the schema in development (Neon); no `.sql` migration file generated

```ts
import { accounts } from "./accounts";
import { categories } from "./categories";
import { dataSourceEnum } from "./shared";
import { authUser } from "./auth";

export const transactions = pgTable(
  "transactions",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    userId: text("user_id")
      .notNull()
      .references(() => authUser.id, { onDelete: "cascade" }),
    accountId: uuid("account_id")
      .notNull()
      .references(() => accounts.id),
    categoryId: uuid("category_id")
      .notNull()
      .references(() => categories.id),
    description: text("description").notNull(),
    amount: numeric("amount", { precision: 12, scale: 2 }).notNull(),
    excludedAmount: numeric("excluded_amount", { precision: 12, scale: 2 }).notNull().default("0"),
    date: date("date").notNull(),
    source: dataSourceEnum("source").notNull().default("manuale"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index("transactions_user_date_idx").on(table.userId, table.date)]
);

export type Transaction = typeof transactions.$inferSelect;
export type NewTransaction = typeof transactions.$inferInsert;

/**
 * Checks the invariant of the "Dividi" (split) mechanism: the excluded share must have
 * the same sign as the amount (or be zero) and an absolute value no greater than it.
 * Application-level validation only, no DB CHECK constraint (per spec decision).
 */
export function isValidExcludedAmount(amount: number, excludedAmount: number): boolean {
  if (excludedAmount !== 0 && Math.sign(excludedAmount) !== Math.sign(amount)) {
    return false;
  }
  return Math.abs(excludedAmount) <= Math.abs(amount);
}
```

```ts
import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";
import { auth } from "@/lib/auth";

export const runtime = "nodejs";

const PUBLIC_PATH_PREFIXES = ["/login", "/api/auth", "/_next", "/favicon.ico"];

function isPublicPath(pathname: string): boolean {
  return PUBLIC_PATH_PREFIXES.some((prefix) => pathname.startsWith(prefix));
}

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (isPublicPath(pathname)) {
    return NextResponse.next();
  }

  const session = await auth.api.getSession({ headers: request.headers });

  if (!session) {
    const loginUrl = new URL("/login", request.url);
    loginUrl.searchParams.set("redirect", pathname);
    return NextResponse.redirect(loginUrl);
  }

  const { onboardingCompleted } = session.user;

  if (!onboardingCompleted && pathname !== "/onboarding") {
    return NextResponse.redirect(new URL("/onboarding", request.url));
  }

  if (onboardingCompleted && pathname === "/onboarding") {
    return NextResponse.redirect(new URL("/", request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon\\.ico).*)"],
};
```

- [ ] **Step 1: Create `app/api/user/onboarding/route.ts`**

```ts
import { NextRequest } from "next/server";
import { eq } from "drizzle-orm";
import { auth } from "@/lib/auth";
import { db } from "@/lib/db/client";
import { authUser } from "@/lib/db/schema/auth";

export async function POST(request: NextRequest) {
  const session = await auth.api.getSession({ headers: request.headers });
  if (!session) {
    return new Response(null, { status: 401 });
  }

  const body = await request.json();
  const { currency } = body as { currency?: string };

  if (!currency || typeof currency !== "string" || currency.trim() === "") {
    return Response.json({ error: "currency è richiesta" }, { status: 400 });
  }

  await db
    .update(authUser)
    .set({ currency: currency.trim(), onboardingCompleted: true })
    .where(eq(authUser.id, session.user.id));

  return new Response(null, { status: 200 });
}
```
