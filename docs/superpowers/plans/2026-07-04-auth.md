# Autenticazione better-auth — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementare l'autenticazione completa (magic link + Google OAuth) con better-auth, sostituire la tabella `users` stub con le 4 tabelle `auth_*`, e creare le pagine `/login` e `/onboarding` con il middleware di protezione route.

**Architecture:** better-auth gestisce il ciclo di vita delle sessioni tramite 4 tabelle Postgres (`auth_user`, `auth_session`, `auth_account`, `auth_verification`). Un middleware Next.js con runtime Node.js protegge tutte le route, reindirizzando gli utenti non autenticati a `/login` e i nuovi utenti (onboarding non completato) a `/onboarding`. Le pagine auth vivono nel route group `(auth)/` senza AppShell; le pagine app vivono nel route group `(app)/` con AppShell. Quando un nuovo utente viene creato, un `databaseHooks.user.create.after` semina automaticamente le categorie di default.

**Tech Stack:** `better-auth` (magic link plugin + Google OAuth), `resend` (invio email), Drizzle ORM (adapter better-auth + query builder), Next.js App Router (route groups, middleware runtime Node.js), React (controlled forms, `useRouter`)

## Global Constraints

- Package manager: `pnpm` (non npm né yarn)
- Tutte le stringhe visibili all'utente: in italiano
- Nessun colore esadecimale hardcoded: usare i token Tailwind (`bg-background`, `text-foreground`, `text-text-2`, `text-text-3`, `bg-primary`, ecc.)
- `user_id` nelle tabelle di dominio: tipo `text` (non `uuid`), per allinearsi al PK `text` di `auth_user`
- Schema Drizzle per le tabelle auth in `lib/db/schema/auth.ts`; `lib/db/schema/users.ts` viene eliminato
- Nessun import circolare: `lib/auth/index.ts` → `lib/db/client.ts` + `lib/db/schema/*`; mai il contrario
- `drizzle-kit push` per applicare lo schema in sviluppo (Neon); nessun file `.sql` di migration generato

```ts
import { date, index, numeric, pgTable, text, timestamp, uuid } from "drizzle-orm/pg-core";
import { accounts } from "./accounts";
import { categories } from "./categories";
import { dataSourceEnum } from "./shared";
import { authUser } from "./auth";

export const transactions = pgTable(
  "transactions",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    userId: text("user_id")
      .notNull()
      .references(() => authUser.id, { onDelete: "cascade" }),
    accountId: uuid("account_id")
      .notNull()
      .references(() => accounts.id),
    categoryId: uuid("category_id")
      .notNull()
      .references(() => categories.id),
    description: text("description").notNull(),
    amount: numeric("amount", { precision: 12, scale: 2 }).notNull(),
    excludedAmount: numeric("excluded_amount", { precision: 12, scale: 2 }).notNull().default("0"),
    date: date("date").notNull(),
    source: dataSourceEnum("source").notNull().default("manuale"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index("transactions_user_date_idx").on(table.userId, table.date)]
);

export type Transaction = typeof transactions.$inferSelect;
export type NewTransaction = typeof transactions.$inferInsert;

/**
 * Verifica l'invariante del meccanismo "Dividi": la quota esclusa deve avere
 * lo stesso segno dell'importo (o essere zero) e valore assoluto non superiore.
 * Validazione solo applicativa, nessun CHECK constraint DB (per decisione di spec).
 */
export function isValidExcludedAmount(amount: number, excludedAmount: number): boolean {
  if (excludedAmount !== 0 && Math.sign(excludedAmount) !== Math.sign(amount)) {
    return false;
  }
  return Math.abs(excludedAmount) <= Math.abs(amount);
}
```

```ts
import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";
import { auth } from "@/lib/auth";

export const runtime = "nodejs";

const PUBLIC_PATH_PREFIXES = ["/login", "/api/auth", "/_next", "/favicon.ico"];

function isPublicPath(pathname: string): boolean {
  return PUBLIC_PATH_PREFIXES.some((prefix) => pathname.startsWith(prefix));
}

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (isPublicPath(pathname)) {
    return NextResponse.next();
  }

  const session = await auth.api.getSession({ headers: request.headers });

  if (!session) {
    const loginUrl = new URL("/login", request.url);
    loginUrl.searchParams.set("redirect", pathname);
    return NextResponse.redirect(loginUrl);
  }

  const { onboardingCompleted } = session.user;

  if (!onboardingCompleted && pathname !== "/onboarding") {
    return NextResponse.redirect(new URL("/onboarding", request.url));
  }

  if (onboardingCompleted && pathname === "/onboarding") {
    return NextResponse.redirect(new URL("/", request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon\\.ico).*)"],
};
```

- [ ] **Step 1: Crea `app/api/user/onboarding/route.ts`**

```ts
import { NextRequest } from "next/server";
import { eq } from "drizzle-orm";
import { auth } from "@/lib/auth";
import { db } from "@/lib/db/client";
import { authUser } from "@/lib/db/schema/auth";

export async function POST(request: NextRequest) {
  const session = await auth.api.getSession({ headers: request.headers });
  if (!session) {
    return new Response(null, { status: 401 });
  }

  const body = await request.json();
  const { currency } = body as { currency?: string };

  if (!currency || typeof currency !== "string" || currency.trim() === "") {
    return Response.json({ error: "currency è richiesta" }, { status: 400 });
  }

  await db
    .update(authUser)
    .set({ currency: currency.trim(), onboardingCompleted: true })
    .where(eq(authUser.id, session.user.id));

  return new Response(null, { status: 200 });
}
```
