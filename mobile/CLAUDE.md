# mobile/ — BuddyBudget phone app (Capacitor)

Native shell of the web app: read "Mobile app (Capacitor)" in the root `CLAUDE.md` first, then `README.md` here.

- Own package.json, lockfile and `pnpm-workspace.yaml`: run pnpm commands **inside `mobile/`**, never from the root
  (the root workspace must not pick up these packages). Plugin versions are exact and identical to the root
  `package.json`.
- `ios/` and `android/` are generated by Capacitor and then edited by hand: after `pnpm sync` keep the edits listed in
  `README.md` (entitlements, Info.plist schemes, AppDelegate push hooks, manifest intent filters, gradle signing) and
  commit the regenerated plugin lists (`capacitor.build.gradle`, `capacitor.settings.gradle`, `CapApp-SPM/Package.swift`).
- No app logic here: screens, APIs and native glue (`lib/native/`) live in the web app. This folder changes only for
  plugins, permissions, icons, shell config and store metadata — each of those needs a store release.
- Secrets (`google-services.json`, `keystore.properties`, `.jks`, `.p8`) are never committed.
- English for code, comments and docs; user-facing strings (Info.plist usage descriptions, offline page) in Italian.
