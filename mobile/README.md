# BuddyBudget mobile (Capacitor)

Native iOS and Android shell of BuddyBudget. The WebView loads the deployed web app (`https://app.buddybudget.io`),
so the screens are the same ones as the web and every release reaches phones without a store update. The shell adds
only what the web cannot do: links that open the app, and (next phases) push notifications, Face ID, widgets.

Design and phases: [`docs/superpowers/specs/2026-10-17-native-app-capacitor-design.md`](../docs/superpowers/specs/2026-10-17-native-app-capacitor-design.md).

## Layout

- `capacitor.config.ts`: app id `io.buddybudget.app`, `server.url` (override with `BUDDYBUDGET_APP_URL`), user agent suffix `BuddyBudgetApp`.
- `www/`: only the offline page shown when the server cannot be reached.
- `ios/`, `android/`: generated by `cap add`, then edited by hand for deep links (keep these edits when regenerating):
  - `ios/App/App/App.entitlements`: Associated Domains `applinks:app.buddybudget.io` (Universal Links).
  - `ios/App/App/Info.plist`: URL scheme `buddybudget`.
  - `android/app/src/main/AndroidManifest.xml`: App Link on `/api/auth/magic-link/verify` and scheme `buddybudget://open`.

The web side lives in the app: `lib/native/` (deep link parsing, `.well-known` bodies), `components/domain/native/`
(`NativeAppBridge`, mounted in the root layout) and `app/.well-known/*` (served only when the `NATIVE_*` env vars are set).

## Run it

Requirements: Node + pnpm; Xcode (macOS) for iOS; Android Studio for Android.

```
cd mobile
pnpm install
pnpm sync          # copies config and plugins into ios/ and android/
pnpm ios           # opens Xcode: pick a simulator or a device and Run
pnpm android       # opens Android Studio
```

Against a local server: `BUDDYBUDGET_APP_URL=http://192.168.1.10:3000 pnpm sync` (the phone must reach your machine;
`cleartext` is turned on automatically for http). Deep links only verify against the real domain.

## Before the stores

1. Apple Developer account (99 $/year) and Google Play Console (25 $ once).
2. Set `NATIVE_IOS_APP_ID` (`<TEAM_ID>.io.buddybudget.app`), `NATIVE_ANDROID_PACKAGE` and `NATIVE_ANDROID_CERT_SHA256`
   (Play App Signing certificate) in the app's Secret, then check `https://app.buddybudget.io/.well-known/apple-app-site-association`
   and `/.well-known/assetlinks.json`.
3. Icons and splash: `npx @capacitor/assets generate` from a 1024×1024 icon (today they are Capacitor's defaults).
