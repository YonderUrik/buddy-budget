## 2. `summarizeCosts(positions, productCountry)`

Country rule: `annualStampDutyRate` = **IT 0.002, DE 0** (`FINANCIAL_COUNTRIES[...].investmentCosts`); unknown country →
error. Rows: positions with `value > 0`; `terCost = value × (ter ?? 0)`; `bolloCost = subjectToBollo ? value × rate : 0`
(`subjectToBollo = type !== "crypto"` in Analytics); `total`, `pct = total/value`; sorted by `total` desc (stable).
`annualCost = Σ total`, `totalValue = Σ value`, `annualPct = annualCost/totalValue` (null if 0),
`missingTerValue = Σ value` of positions with `value > 0 && ter === null` (UI warns the real cost is higher).

## 3. `costDrag(value, grossReturn, annualCostPct, years)`

For `year = 0…years`: `withoutCosts = value(1+r)^year`, `withCosts = value(1 + r − c)^year` (**arithmetic** subtraction of
the cost rate, not `(1+r)(1−c)`), `lost = withoutCosts − withCosts`. No contributions.

## 4. `computeCostImpact(params, unpriced, report)`

Charges per date from transactions up to today (`split`/`rettifica` skipped): `fees += Number(fees)`,
`taxes += Number(taxes)`; plus `estimatedTaxCharges(report, today)` as `estimatedTaxes` (IT only; `report = null` in DE).
Totals: `fees`, `taxes = recorded + estimated`, `estimatedTaxes`. If there are no transactions or some open position is
unpriced (`unpriced = summary.unpricedCount > 0`) → `available = false`, no series. Otherwise, over daily returns from
the day before the first transaction to today: `growth = 1 + (ret ?? 0)` (abort → unavailable if non-finite or < 0);
`saved_x = saved_x × growth + paid_x(day)` for each of fees, taxes, estimatedTaxes; store per day. The chart window does
**not** affect it (always full history).

## 5. Toggles

`reinvestedFrom(day, includeFees, includeTaxes) = (includeFees ? 0 : fees) + (includeTaxes ? 0 : taxes + estimatedTaxes)`
— `include = true` means "costs stay deducted" (the real situation, default). `reinvestedAmount(impact, date, …)` = that
for `additions[date]` (0 if unavailable/missing). `reinvestmentEffects(impact)` = effect of each switch alone on the last
day. `simulateCostExclusions(impact, series, value, includeFees, includeTaxes)`: inactive when unavailable or both
included; else `value + extra(lastDay)` and each series point `+ reinvestedAmount(point.date)` (month-end points pick the
addition of their own date).
