## FIRE formulas (`lib/calc/fire.ts`)

- `fireNumber(S, w)` = `S / w`; `null` unless `S ≥ 0` and `w > 0` (NaN-safe: written as `!(S >= 0)`).
- `fireNumberAfterTax(G, τ)` = `G / (1 − τ)`; `null` unless `0 ≤ τ < 1`.
- `wealthAfterYears({P, c, r}, n)`: `n ≤ 0 → P`; `|r| < 1e-12 → P + c·n`; else `P·(1+r)^n + c·((1+r)^n − 1)/r` (saving at year end).
- `yearsToTarget({P, c, r}, T)` (fractional years):
  `P ≥ T → 0`. If `|r| < 1e-12`: `c ≤ 0 → null`, else `(T−P)/c`. Else `top = T·r + c`, `bottom = P·r + c`;
  `top ≤ 0 || bottom ≤ 0 → null`; `n = ln(top/bottom)/ln(1+r)`. Return `null` if non-finite, `< 0`, or `> 80`.
- `coastNumber(T, r, n)` = `n ≤ 0 ? T : T / (1+r)^n`.
- `leanSpending({dovuta, saltuaria})` = sum.
- `sensitivityByRateAndReturn`: cell = `yearsToTarget({current, annualSaving, r_col}, fireNumber(S, w_row))`.
- `sensitivityBySpendingAndSaving`: `spending = S(1+Δs)`, `target = fireNumber(spending, w)`,
  `saving = A(1+Δa) − (spending − S)` (spending less frees saving), cell = `yearsToTarget({current, saving, r}, target)`.
- `savingsRate(I, E)` = `I > 0 ? (I−E)/I : null`; `monthsOfCoverage(a, m)` = `m > 0 ? a/m : null`.
- Display: years shown with 1 decimal in tables (`years.toFixed(1)` then `.`→`,`; 0 → "ok", null → "—");
  "arrival year" = `currentYear + ceil(yearsToFire)`; 0 → "Già qui".

## Plan (`resolvePlan(base, a)`)

1. `cashflowFromData`: if `base.cashflow.monthsWithData ≥ 3`: `spending = annualSpending > 0 ? annualSpending : null`,
   `savings = annualSavings`; else both `null`.
2. `spending = a.annualSpending ?? dataSpending`; `savings = a.annualSavings ?? dataSavings`.
   Source: `"ipotesi"` if the assumption is non-null, `"dati"` if from data, else `"manca"`.
3. `wealth = liquidity + investments + (includePensionFunds ? pension : 0)` (debts are NOT subtracted).
4. `liquidation = computeLiquidation(base.positions)`;
   `taxShare = includeLatentTax && wealth > 0 ? min(latentTax / wealth, 0.99) : 0`.
5. `gross = fireNumber(spending, withdrawalRate)`; `target = fireNumberAfterTax(gross, taxShare)`.
6. `progress = target > 0 ? wealth/target : null` (UI clamps display to 9.99 / 999%).
7. `yearsToFire = yearsToTarget({wealth, savings ?? 0, expectedReturn}, target)`.
8. `coast = COAST_HORIZONS.map(y => {years: y, number: coastNumber(target, expectedReturn, y)})` (empty if no target).

### `computeLiquidation(positions)`
`tax_i = max(0, unrealizedGain_i) × taxRate_i` (losses don't offset; no zainetto); keep `tax > 0`, sort by tax desc;
`latentTax = Σ tax`; `grossValue = Σ value`; `netValue = gross − latent`; `taxRatio = gross > 0 ? latent/gross : null`.
Position `taxRate` comes from the server (`0.26` default, `0.125` for government bonds, see investments/taxes spec).

### Scenario sliders (`lib/analitiche/scenario.ts`)
- `scenarioSlider(field, baseline)`:
  `expectedReturn → {−0.02, 0.5, 0.001}`; `withdrawalRate → {0.02, 0.06, 0.001}`;
  `annualSpending → baseline == null ? null : {0, roundUp(max(2·baseline, 12000), 500), 100}`;
  `annualSavings → baseline == null ? null : {min: baseline < 0 ? roundDown(2·baseline, 500) : 0, max: roundUp(max(2·|baseline|, 12000), 500), step 100}`.
  `roundUp(v,to) = ceil(v/to)·to`, `roundDown = floor(v/to)·to`.
- Slider `onChange`: if `|v − baseline| < step/2` the override is removed (back to baseline).
- `applyScenario(a, overrides)` = shallow merge. `hasScenario` = any of the 4 fields set.
- Scenario plan = `hasScenario ? resolvePlan(base, applied) : plan`.
- `yearsToFireWith(plan, a, overrides)`: per-slider "gain" label. Uses `plan.taxShare` and `plan.wealth` unchanged:
  `target = fireNumberAfterTax(fireNumber(spending', w'), plan.taxShare)`, `yearsToTarget({plan.wealth, savings', r'}, target)`.
- Baseline for sliders: `plan.savings`, `plan.spending`, `assumptions.expectedReturn` (already resolved from history), `assumptions.withdrawalRate`.

### Expected return (`resolveExpectedReturn`)
- `historyReal = history.ok ? (history.real ?? (1+nominal)/(1+a.inflation) − 1) : null`.
- `!a.expectedReturnAuto → value = a.expectedReturn, source "manuale"`;
  else no history → `0.04, "prudente"`;
  else `clamped = clamp(historyReal, −0.02, 0.5)`, `value = round(clamped·1000)/1000`, `source "storico"`.
- `high = value > 0.08`.

### Assumptions persistence
`resolveAssumptions(stored)`: start from defaults, accept each stored field only if it passes its own schema (invalid field →
default, never an error). If `expectedReturnAuto` absent: `auto = (expectedReturn === 0.04)`.
`mergeAssumptions(cur, upd)`: if `upd.expectedReturn` is set without `expectedReturnAuto`, force `expectedReturnAuto=false`.
Mobile sends PATCH, server merges; mobile need not port these.

### Data period (`lib/analitiche/period.ts`)
`{kind:"ultimi", months: 12|24}` or `{kind:"personalizzato", from:"YYYY-MM", to:"YYYY-MM"}` (3…120 months).
`resolvePeriodRange`: `lastFull = endOfMonth(today − 1 month)`. Preset: `from = startOfMonth(lastFull − (months−1))`.
Custom: `to = min(endOfMonth(to), lastFull)`; current month never counts. Only needed on mobile for the period
picker labels; the base comes from the server.

## Monte Carlo (`lib/calc/monte-carlo.ts`) — bit-exact spec

### PRNG: mulberry32 (all arithmetic is unsigned 32-bit, wrap-around)
```
state a = seed mod 2^32
next():
  a = (a + 0x6D2B79F5) mod 2^32
  t = a
  t = imul(t ^ (t >>> 15), t | 1)
  t = t ^ (t + imul(t ^ (t >>> 7), t | 61))      // + is mod 2^32
  return ((t ^ (t >>> 14)) as uint32) / 4294967296.0
```
`imul` = low 32 bits of the product. Swift: use `UInt32` with `&+`, `&*`, `>>`. Kotlin: use `Int` with `*`, `+`
(wraps), `ushr`, and convert the final value with `.toUInt().toDouble()` (or `toLong() and 0xFFFFFFFFL`).
Result is exactly representable → must match **bit-for-bit**.

### Per-path seed
`pathSeed(seed, i) = (imul(seed ^ 0x9E3779B9, 0x85EBCA6B) + imul(i + 1, 0xC2B2AE35)) mod 2^32`
(JS adds two signed int32 in double precision then `>>> 0`, which is the same as unsigned wrap-around addition).
Each path `i` gets its own `mulberry32(pathSeed(seed, i))` → the same random numbers are used for every withdrawal
rule (common random numbers) and paths are independent of path count.

### Normal draws (Box–Muller, cosine branch only)
`u = max(next(), 2.220446049250313e-16)` (Number.EPSILON), `v = next()`, `z = sqrt(−2·ln u) · cos(2π·v)`.
Two uniforms per normal; the sine half is discarded.

### Lognormal yearly growth
`mean = 1 + expectedReturn`; `var = ln(1 + (vol/mean)^2)`; `mu = ln(mean) − var/2`; `sd = sqrt(var)`;
growth factor `g = exp(mu + sd·z)`.

### Algorithm (`runMonteCarlo(input)`)
```
paths = clamp(round(input.paths ?? 3000), 1, 10000); seed = input.seed ?? 1
accum = max(0, round(accumulationYears)); ret = max(1, round(retirementYears)); inflation = input.inflation ?? 0.02
pension = publicPension if publicPension.annual > 0 else none; pensionStart = pension ? max(0, round(startsAfterYears)) : ∞
for each path i:
  rand = mulberry32(pathSeed(seed, i)); W = startingWealth; wealth[0][i] = W
  repeat accum times (y): W = max(0, W·g() + annualSavings); wealth[y+1][i] = W        // one normal per year
  need0 = max(0, annualSpending − (pensionStart == 0 ? pension.annual : 0))
  rate0 = W > 0 ? need0 / W : 0; prev = need0; rate = rate0; lastReturn = 0; ruined = false; minSpend = annualSpending
  for k in 0..<ret:
    pensionNow = k ≥ pensionStart ? pension.annual : 0; remaining = ret − k
    if k > 0 and k == pensionStart: rebased = max(0, prev − pension.annual); if prev > 0: rate *= rebased/prev; prev = rebased
    if ruined or W ≤ 0: wd = 0
    elif rule == fissa:        wd = max(0, annualSpending − pensionNow)
    elif rule == percentuale:  wd = rate·W
    elif rule == guyton-klinger:
        wd = k == 0 ? need0 : (lastReturn < 0 and prev/W > rate0 ? prev/(1+inflation) : prev)
        cur = wd / W
        if cur > rate0·1.2 and remaining > 15: wd *= 0.9
        elif cur < rate0·0.8: wd *= 1.1
    else (vanguard):
        wd = k == 0 ? need0 : min(max(rate0·W, prev·(1−0.025)), prev·(1+0.05))
    wd = min(wd, W); prev = wd
    spent = wd + pensionNow; spending[k][i] = spent; minSpend = min(minSpend, spent)
    W −= wd; g = g(); lastReturn = g − 1; W *= g                      // withdrawal at start of year, then growth
    if !ruined and (W ≤ 0 or (rule == fissa and wd < annualSpending − pensionNow − 1e-9)):
        ruined = true; ruinCounts[k...ret−1] += 1
    if ruined: W = 0
    wealth[accum + k + 1][i] = W
  first = spending[0][i]
  cut[i] = first > 0 ? max(0, 1 − minSpend / max(first, annualSpending)) : 1
  ending[i] = W; if !ruined: successes += 1
```
Note: a ruined path still consumes one normal per remaining year (the draw happens before the ruin check and continues
afterwards) — keep the draw sequence identical.

Outputs: per-year wealth bands p10/p25/p50/p75/p90 (year 0…accum+ret), spending bands p10/p50/p90 per retirement year,
`ruinByYear[k] = ruinCounts[k]/paths`, `successRate = successes/paths`, `endingWealth` p10/p50/p90, `maxCut` p50/p90.
`percentile(sorted, p)`: `pos = clamp(p,0,100)/100 · (n−1)`, linear interpolation between `floor(pos)` and `ceil(pos)`;
empty → 0. Sort ascending with numeric compare.

`compareRules(input)` = run for `["fissa","percentuale","guyton-klinger","vanguard"]` (this order) with the same seed.

`buildSimulationInput(plan, a, retireAt, rule = a.rule)`: `null` if `plan.spending` is null or ≤ 0. Otherwise
`startingWealth = max(0, plan.wealth)`, `annualSavings = max(0, plan.savings ?? 0)`,
`accumulationYears = retireAt == "fire" && yearsToFire != null ? min(ceil(yearsToFire), 40) : 0`,
`retirementYears = a.retirementYears`, `annualSpending = plan.spending`, `expectedReturn`, `volatility`, `inflation`,
`rule`, `publicPension ?? undefined`. Simulation tab default `retireAt = "oggi"`; the compact variant forces "oggi".

### Cross-platform determinism
- PRNG, path seeds, sorting and percentile are exact.
- `ln`, `cos`, `exp`, `pow` are the only transcendental calls. V8 uses fdlibm-derived implementations.
  **Kotlin: use `StrictMath.log/cos/exp/pow`** (fdlibm, expected bit-identical). **Swift: Darwin libm** may differ by ≤1 ulp
  in rare inputs; a 1-ulp difference changes money values by ~1e-12 relative.
- Test tolerances: uniforms and path seeds **exact**; gaussians 1e-15 abs; money values 1e-9 **relative**;
  `successRate`, `ruinByYear`, `paths` **exact** (they are counts). A threshold flip (ruin detection, GK band) from an ulp
  difference is theoretically possible but was not observed in the vectors; if a Swift test fails only on a count, compare
  the per-path trace with the 3-path `runMonteCarlo-tiny-full` vector.
- Performance: 4 rules × 3000 paths × (accum + 40) years ≈ 0.5M steps per slider change. Run on a background
  thread/coroutine, debounce/defer like the web (`useDeferredValue`), and keep the latest result while computing.

## Costs (`lib/calc/costs.ts`)
`summarizeCosts(positions, country)`: positions with `value > 0`; `terCost = value × (ter ?? 0)`,
`bollo = subjectToBollo ? value × annualStampDutyRate (IT 0.002, DE 0) : 0`, `pct = total/value`; sort by total desc;
`annualPct = totalValue > 0 ? annualCost/totalValue : null`; `missingTerValue = Σ value where ter == null`.
`subjectToBollo = instrument.type != "crypto"`. TER per instrument comes from `assumptions.terByInstrument[id] ?? null`.
`costDrag(V, r, c, years)`: for y in 0…years: `without = V(1+r)^y`, `with = V(1+r−c)^y`, `lost = without − with`.
Called with `r = assumptions.expectedReturn`, `years = 30`.

## Growth split (`splitGrowth(points)`)
For i ≥ 1: `delta = nw_i − nw_{i−1}`, `fromSavings = savings_i`, `fromMarket = delta − savings_i`.
Totals summed; `savingsShare = totalDelta > 0 ? totalFromSavings/totalDelta : null`.

## Edge cases checklist
- Missing spending (`plan.spending == null`) → all FIRE/MC cards show "missing data" message; sliders for spending/savings hidden.
- Negative savings are allowed in the plan (slider can go negative) but MC uses `max(0, savings)`.
- `withdrawalRate` row values in the FIRE table are clamped to ≥ 0.01 before computing.
- `taxShare` capped at 0.99 to avoid division by ~0.
- Years > 80 → `null` → "—"; already at target → 0 → "ok"/"Già qui".
