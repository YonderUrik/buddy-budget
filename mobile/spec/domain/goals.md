## Constants (`lib/goals/constants.ts`)
`GOAL_KINDS = [emergenza, viaggio, casa, acquisto, altro]`; `KEPT_GOAL_KINDS = [emergenza]` (money stays in net worth when
reached, so it never shifts FIRE); `EMERGENCY_MONTH_CHOICES = [3, 6, 12]`, default 6; `MAX_GOALS = 20`;
`MAX_GOAL_SOURCES = 12`; `OVERVIEW_GOALS = 3` (Panoramica shows the 3 closest); `GOAL_DEADLINE_LEAD_DAYS = 30` (email);
`GOAL_HORIZON_MONTHS = 600`. Wizard steps: `tipo → quanto → fonti → ritmo → riepilogo`. Name length 1…80 (trimmed).

## Month helpers
- `monthsBetween(from, to)` = `(ty·12 + tm) − (fy·12 + fm)` using only year/month (day ignored; accepts `YYYY-MM` or `YYYY-MM-DD`).
- `addMonthsKey(from, n)`: `index = y·12 + (m−1) + n` → `"${floor(index/12)}-${pad2(index mod 12 + 1)}"` (returns `YYYY-MM`).

## Server view (for understanding the payload)

### Source allocation (`buildGoalsView`)
1. Order goals by `priority` asc, then `createdAt` asc.
2. Each account starts with `left = max(0, balance)`, each position with `max(0, value)`; goals higher in the list take first.
3. Per source: `gross = min(max(0, amount), left)`; `left −= gross`.
   Instruments: `taxPerEuro = value > 0 && gain > 0 ? gain/value × taxRate : 0`; `tax = round2(gross × taxPerEuro)`.
   `counted = round2(gross − tax)`; `short = gross + 0.005 < amount` (account/position shrank or over-assigned).
   `round2(n) = Math.round(n·100)/100`.
4. `current = Σ counted`.
5. Free sources: `free = round2(left)` per account/position, with `taxPerEuro` for instruments.
6. `capacity = plan.savings / 12` (Analytics plan; `null` if unknown); `essentialMonthly = (base.cashflow.leanSpending ?? plan.spending)/12`;
   FIRE input = `{wealth, annualSavings: plan.savings, realReturn: assumptions.expectedReturn, target: plan.target}` or `null`.

### Plan (`buildGoalsPlan`)
- `available = capacity == null ? +∞ : max(0, capacity)`.
- Per goal (priority order): `current = max(0, current)`, `remaining = max(0, target − current)`,
  `progress = target > 0 ? min(1, current/target) : 1`.
  Achieved or `remaining ≤ 0.005` → status `raggiunto`, funded 0.
  Else `wanted = max(0, monthly)`; `requested += wanted`; `funded = min(wanted, available)`; `available −= funded`.
  `monthsLeft = targetDate ? monthsBetween(today, targetDate) : null`; `required = monthsLeft == null ? null : remaining / max(1, monthsLeft)`.
  `monthsToGo = funded > 0.005 ? ceil(remaining/funded − 1e-9) : null`; `etaMonth = addMonthsKey(today, monthsToGo)`.
  Status: `monthsToGo == null → fermo`; no date → `senza_data`; `monthsToGo ≤ max(0, monthsLeft) → in_linea` else `in_ritardo`.
- `gap = capacity == null ? 0 : max(0, requested − max(0, capacity))`.
- FIRE: `monthsToFire(fire, withdrawals)`: if `wealth ≥ target` and no withdrawals → 0; monthly rate `(1+r)^(1/12) − 1`,
  monthly saving `annualSavings/12`; for month 1…600: `W = W(1+m) + s − withdrawal[month]`; first month with `W ≥ target`;
  else `null`. Spending goals (not `emergenza`, with an ETA) withdraw their `target` at their `monthsToGo`.
  `withGoalsMonths` uses all of them; per-goal `fireShiftMonths = monthsToFire(with only that goal) − baseMonths`
  (`emergenza` not yet reached → 0). View converts months to years with `addMonthsKey(today, months).year`.

## Client wizard helpers (port 1:1)
- `emergencyTarget(essentialMonthly, months) = round(essentialMonthly × months / 100) × 100` (JS `Math.round`, half up).
- `assignedTotal(draft) = Σ draft.sources values` (gross, before instrument tax).
- `isCovered(draft) = target > 0 && assignedTotal ≥ target`.
- `requiredMonthly(draft, todayKey)`: `null` without `targetMonth` or target; else
  `ceil(max(0, target − assigned) / max(1, monthsBetween(todayKey, targetMonth)))`.
- `availableSources(view, goal)`: each source's `free` plus this goal's own current `counted + tax`; keep sources with
  `total > 0` or already used by this goal.
- `canAdvance`: tipo → kind set and name 1…80; quanto → target > 0 and (no month or month > current month);
  fonti → ≤ 12 sources, all amounts > 0; ritmo → monthly ≥ 0 or covered; riepilogo → true.
- `withKind`: if the name was empty or the previous kind's default name, replace with the new kind's default name; choosing
  `emergenza` with known `essentialMonthly` and no target pre-fills 6 months.
- `toPayload`: `targetDate = targetMonth + "-01"`, `monthlyAmount = monthly ?? 0`, sources split into `{accountId|instrumentId, amount}`.
