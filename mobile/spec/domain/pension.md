## Data model

```
PensionSnapshot { id: String, date: "YYYY-MM-DD", netContributions: Double, value: Double }
PensionFundData { id, name, adhesionDate: "YYYY-MM-DD", snapshots: [PensionSnapshot] (date ASC) }
```
Limits (`lib/pension/limits.ts`): max 10 funds/user, 5000 snapshots/fund, 1000 rows per file import.

## Date helpers (exact semantics matter)

- Dates are ISO strings `YYYY-MM-DD`, compared **lexicographically**. Do not convert to timezone-aware dates for comparisons.
- `daysBetween(a,b)` (from `lib/calc/returns.ts`) = `round((parse(b) − parse(a)) / 86_400_000)`; `parseDateOnly` builds a
  local-midnight date — the `round` absorbs DST. On mobile compute with a UTC calendar: identical results.
- `addMonths(key, n)`: total = y·12 + (m−1) + n; year = floor(total/12); month = total mod 12 (JS `%` on a non‑negative total);
  day = min(d, lastDayOfTargetMonth). `2024-01-31 +1 → 2024-02-29`, `2026-03-31 −1 → 2026-02-28`.
- `wholeYearsBetween(from, to)`: `yearDiff − (to[5:] < from[5:] ? 1 : 0)`, clamped ≥ 0 (compare the `MM-DD` strings).

## Functions

### `deriveContributions(snapshots, adhesionDate) → [ {date, amount, estimated} ]`
1. Sort snapshots by date (stable, string compare). Empty → `[]`.
2. First snapshot with `netContributions > 0`:
   - if `adhesionDate` is non-null and `< first.date`: spread `first.netContributions` evenly over
     `payments = max(1, round(months / 3))` where `months = max(1, round(daysBetween(adhesion, first.date) / (365/12)))`.
     Payment k (1…payments) is dated `toKey(utc(start) + round(spanMs·k/payments))` (UTC ms, then ISO date), amount
     `net/payments`, `estimated=true`.
   - else one payment on `first.date` with the full amount, `estimated=false`.
3. For each next snapshot: `delta = net[i] − net[i−1]`; push if `|delta| > 0.005` (can be negative = withdrawal).

### `computePensionPerformance(snapshots, adhesionDate) → PensionPerformance | null`
- `null` if no snapshots.
- Cash flows: each derived contribution as `−amount` at its date, plus `+last.value` at `last.date`.
- `firstDate = contributions[0]?.date ?? sorted[0].date`; `days = daysBetween(firstDate, last.date)`.
- `annualReturn = moneyWeightedReturn(flows, days)?.annual` → XIRR (see `domain/investments` / returns spec):
  bisection on the **log daily rate** `h ∈ [−b, b]`, `b = min(1, 500/span)`, 200 iterations,
  `npv(h) = Σ amount·exp(−h·daysFromFirst)`, flows with `|amount| ≤ 1e-6` dropped, requires both signs, `null` if
  `npv(−b)` and `npv(b)` have the same sign or are non-finite. Daily rate = `exp((lo+hi)/2) − 1`, annual = `(1+daily)^365 − 1`.
  `null` when `days ≤ 0`.
- `gain = last.value − last.netContributions`; `gainPct = gain / net` if `net > 0` else `null`;
  `approximate = any contribution estimated`.

### `exitTaxRate(years) = max(0.09, 0.15 − max(0, years − 15) × 0.003)`
### `exitTaxMilestones(adhesion)` → `{ reductionStartsOn: addMonths(adhesion, 180), minRateOn: addMonths(adhesion, 35·12) }`
(35 = 15 + round((0.15−0.09)/0.003)).

### `withdrawalScenarios(value, netContributions, adhesionDate, today, yearsOverride?) → 3 scenarios`
- `years = yearsOverride ?? (adhesion ? wholeYearsBetween(adhesion, today) : 0)`; `reduced = exitTaxRate(years)`.
- `base = min(value, max(0, netContributions))`.
- For each `(reason, rate)` in `[("pensionamento", reduced), ("sanitarie", reduced), ("altri", 0.23)]`:
  `netLow = value − rate·max(0, value)` (prudent: tax on whole value), `netHigh = value − rate·base` (tax on contributions only).
- Order of the returned array is fixed (UI relies on it).

### Rate simulation (`useRateSimulation`) — interactive
- `realYears = adhesion ? wholeYearsBetween(adhesion, today) : 0`.
- `setYears(n)` stores `clamp(round(n), 0, 35)`; a simulated value equal to `realYears` counts as "no simulation".
- State resets when `adhesionDate` changes (fund switch). `reset()` clears it.
- `scenarios = simulated ? withdrawalScenarios(..., simulated) : baseline`; `rate = exitTaxRate(years)`.
- `commit()` (on gesture end) fires product event `pension_rate_simulated {years}` only when simulated.
- Timeline keyboard steps (web): arrows ±1, PageUp/PageDown ±5; first 15 years drawn as flat segment.

### `companyTfrValue(contributions, asOf, inflationRate) → {gross, net, annualRate}`
`annualRate = 0.015 + 0.75·inflation`. For each contribution: `years = max(0, daysBetween(c.date, asOf)) / 365`,
`grown = amount·(1+annualRate)^years`; `gross += grown`; `net += amount + (grown − amount)·(1 − 0.17)`.
Called with `asOf = last.date`, `inflation = 0.02`. The compare card shows `diff = fundValue − net`,
`diffPct = net > 0 ? diff/net : null`, `better = diff ≥ 0`.

### `recentQuarterlyContribution(snapshots) → Double | null`
`null` if < 2 snapshots. `windowStart = last.date − 365 days` (UTC). `before` = latest snapshot with `date ≤ windowStart`,
else the first. `days = daysBetween(before, last)`; `< 270 → null`.
Result `(last.net − before.net)/days × 365/4`. Context uses `?? 0`. Projection card initial contribution =
`round(quarterly/20)·20`.

### `projectPension({startValue, quarterlyContribution, years, rates}) → [ProjectionPoint]`
`total = max(0, round(years))`; point 0 = start. For each year, 4 quarters, each scenario:
`v = v·(1+r)^(1/4) + quarterlyContribution` (contribution at end of quarter). One point per year end.
Card also shows `paidIn = contribution × 4 × years`. Values are in "today's euros" (rates are real).

### `yearlyBreakdown(snapshots) → [YearBreakdown]`
Last snapshot of each calendar year; years without snapshots are skipped. Starting from `{net:0, value:0}`:
`contributions = end.net − prev.net`, `gain = end.value − prev.value − contributions`,
`returnRate = (prev.value + contributions) > 0 ? gain / that : null`,
`partial = end is the overall latest snapshot && !end.date.endsWith("-12-31")`.

### `pensionTotalOn(funds, date)` (net-worth)
Sum over funds of the value of the latest snapshot with `date ≤ given date` (0 before the first).

## Rounding & display
No rounding inside calculations; formatting only at display (currency with 2 decimals, percent with
`formatPercent(x, 1)` for rates; see `formatting-localization.md`). Rates like `0.15 − 6·0.003` are computed in doubles —
compare with tolerance 1e-12.

## Edge cases checklist
- No funds → empty state; fund without snapshots → `PensionNoSnapshots`; scenarios `[]`, `tfr = null`, `quarterly = 0`.
- Negative deltas (withdrawals/transfers out) are kept as negative contributions.
- `adhesionDate ≥ first.date` → no estimated spreading.
- `value < netContributions` → `base = value` (no negative tax).
- Years > 45 not reachable from the projection slider; `years` is always rounded.
