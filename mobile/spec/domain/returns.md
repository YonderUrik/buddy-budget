Sources (web repo, read-only): `lib/calc/returns.ts`, `lib/calc/performance-range.ts`, `lib/calc/return-heatmap.ts`,
`lib/investments/period-gain.ts`, `lib/investments/chart-period.ts`, `lib/investments/return-heatmap-view.ts`,
`lib/queries/performance.ts`, `components/domain/investments/{returns-card,returns-chart,benchmark-summary,return-heatmap-card,return-heatmap-grid,period-gain-summary}.tsx`.

Machine-readable golden vectors: [`vectors/returns.json`](vectors/returns.json) (26 cases, generated by running the
TypeScript sources; `tolerance` 1e-9 absolute; numbers rounded to 12 significant digits). Positions, prices, FX and
daily values are defined in [investments.md](investments.md). All returns are **fractions** (0.08 = +8 %).

## 2. Period bounds — `resolvePerformanceRange(transactions, period, today, range?)`

`first` = first transaction date; `start = range?.from ?? periodStartKey(period)` (today minus 1/3/12 months, clamped to
month end; `max` = first transaction); `fromKey = max(start, first)`; `toKey = min(range?.to, today)`; `null` if
`fromKey > toKey` or no transactions. `baseKey = fromKey − 1 day` (the opening value). Chart periods:
`1mese`, `3mesi`, `1anno`, `max`, `ytd` (`{from: YYYY-01-01, to: today}`), `custom` (valid real calendar dates,
`from ≤ to ≤ today`; invalid custom → preset). When a range is given, returns use `max` as the calculation period.

## 3. Daily flows and daily returns

`toDailyFlows(points)` (points from `computeDailyPortfolioValues(baseKey..toKey)`): for each day after the first,
`inflow = Δbought`, `outflow = Δ(bought − invested)` (cash received from sells/redemptions), `income = Δincome`.

`computeDailyReturns(baseValue, flows)` — flows are assumed **at end of day**:

- if previous value `> 1e-6`: `gain = (V + outflow + income) − inflow − V_prev`; `ret = gain / V_prev`;
- else if `inflow > 1e-6` (first purchase): `gain = (V + outflow + income) − inflow`; `ret = gain / inflow`;
- else `ret = null`, `gain = 0` (nothing invested).

`computeTwrSeries`: `index *= 1 + ret` for non-null days, `cumulative = index − 1`.
`annualize(r, days) = (1 + r)^(365/days) − 1`, `null` if `days ≤ 0` or `r ≤ −1`. Annual figures are shown only when
`days ≥ 365` (`showAnnual`).

## 4. Money-weighted return (XIRR)

`investorCashFlows(baseDate, baseValue, flows, endValue)`: `−baseValue` at baseDate; per day `−inflow` (if ≠ 0) and
`outflow + income` (if ≠ 0); `+endValue` at the last flow date (or baseDate).

`xirrDaily(flows)`: drop `|amount| ≤ 1e-6`; require at least one positive and one negative; `t_i` = calendar days from the
earliest date (`daysBetween` = rounded difference of local midnights). Solve `Σ a_i·e^(−h·t_i) = 0` for the **log daily
rate** `h` by **bisection**: bounds `±min(1, 500/max(1, span))`, require finite NPVs of opposite sign at the bounds
(else `null`), exactly **200 iterations** (`mid = (low+high)/2`; keep `low` when `sign(npv(mid)) === sign(npv(low))`),
result `e^((low+high)/2) − 1`. **Do not replace with Newton** — the vectors pin the bisection result.
`moneyWeightedReturn(flows, days)`: `period = (1+d)^days − 1`, `annual = (1+d)^365 − 1`. `days` for the period is
`max(1, daysBetween(base.value > 1e-6 ? baseKey : fromKey, toKey))`, 0 when `toKey === baseKey`.

## 5. Inflation and real return

`inflationBetween(points, fromKey, toKey)`: start = index point whose month equals `fromKey`'s month **exactly**; end =
latest point with month ≤ `toKey`'s month; `null` if missing, `end.month ≤ start.month` or start ≤ 0.
`rate = end/start − 1`, `throughMonth = end.month`. `realReturn = (1 + nominal)/(1 + inflation) − 1` (applied to TWR).
Inflation is supplied only when the user's currency has a national index (IT/DE EUR; see `inflationAreaForCountry`).

## 6. Benchmark — `simulateBenchmark(baseDate, baseValue, flows, priceAt)`

"Same deposits in the benchmark": buy `baseValue / P0` units at the base price, then each day buy `inflow/P` and sell
`(outflow + income)/P` at that day's close (price in user currency, last available on/before). If a withdrawal exceeds
the units (`> units + 1e-6`) → `depleted = true`, units floor at 0. Any missing price → whole simulation `null`
(`benchmarkStatus = "missing_prices"`). Output: `value = units × lastPrice`, `twr = lastPrice/P0 − 1` (price-only),
daily `cumulative`, and investor cash flows with the benchmark end value (for its money-weighted return).

## 7. Chart series

`series` = `[{date: baseKey, portfolio: 0, benchmark: 0 | null}] + TWR cumulative per day`, sampled with
`samplePeriodSeries` (daily for `1mese`/`3mesi`, ranges and `dailySeries: true`; month-end otherwise — see
investments.md). The web's overview always passes `dailySeries: true`.

## 8. Period gain — `computePeriodGain`

Same bounds as §2 (but without clamping `fromKey` to the first transaction when a range is passed). `gain = Σ daily gain`
(equals `endValue − startValue − netContributions + income`), `netContributions = Σ(inflow − outflow)`,
`income = income_end − income_base`, `twr = Π(1+ret) − 1` or `null` if never invested.

## 9. Return heatmap — `buildReturnHeatmap(daily, grouping, todayKey)`

Input: `computeHistoryDailyReturns` = daily returns from the first transaction to today (independent of the chart period).
Constants: `HEATMAP_DAY_WINDOW = 364`, `HEATMAP_SCALE_PERCENTILE = 0.9`, `HEATMAP_FLAT_THRESHOLD = 0.0005` (0.05 %),
`HEATMAP_LEVELS = 4`, `MIN_LABEL_GAP_COLUMNS = 3`, `WEEKEND_START = 5` (row index of Saturday).

- Start at the first day with a non-null return; days after `todayKey` are excluded.
- Buckets: `giorno` = date; `settimana` = ISO week key `"{year}-W{ww}"` (ISO-8601, Monday-based, Thursday rule);
  `mese` = `YYYY-MM`; `anno` = `YYYY`. Bucket `ret = Π(1+r) − 1` over non-null days, `gain = Σ gain`; `null` if no
  non-null day.
- Grids: **day** = columns are weeks from `monday(today − 364)` to today, rows Mon..Sun, month label on the first column
  of a new month if ≥ 3 columns since the previous label; future days `null`; the Sat/Sun rows are **removed** when none
  of their cells is "moving" (|ret| ≥ 0.0005) — crypto keeps them. **week** = rows years (newest first) × 53 ISO weeks,
  column labels on weeks 1, 5, 9, … **month** = rows years (newest first) × 12 months + a year-total cell. **year** = one
  row, columns oldest → newest.
- `scale` = value at index `floor(0.9 × (n − 1))` of the ascending |ret| of the **moving** cells (0 if none).
  `level(ret) = 0` if `ret` null, `|ret| < 0.0005` or `scale ≤ 0`; else `clamp(ceil(|ret|/scale × 4), 1, 4)`; computed for
  cells **and** year totals. `positive`/`negative` count cells with `ret ≥ 0.0005` / `≤ −0.0005`; `counted` = cells with a
  return (totals excluded). Colour by sign (pos/neg tokens) and level (see design/charts.md).
- Labels are localised (`Intl` with the user locale): weekday short names, month short/long, "Settimana dal {0} {1}".
