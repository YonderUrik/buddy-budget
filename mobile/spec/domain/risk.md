## 3. Observations

`riskObservations(daily)`: keep days with non-null `ret`, **drop Saturday/Sunday days whose return is exactly 0** (closed
markets would understate volatility; crypto weekends move and stay). `observationsPerYear(n, calendarDays) =
n × 365 / calendarDays` where `calendarDays` = number of days with non-null return (≈252 with stocks, 365 with only
crypto); `null` if `n = 0` or `calendarDays ≤ 0`.

## 4. Statistics

- `mean`, `sampleStd` (n − 1 denominator; `null` with < 2 values), covariance (n − 1).
- `correlation(x, y)` = cov/(sx·sy), clamped to [−1, 1]; `null` if lengths differ, n < 2 or a std is 0/null.
- `beta(x, y)` = cov(x, y)/var(y); `null` if std(y) is 0/null.
- **Volatility** = `sampleStd(returns) × √perYear`, only with ≥ 20 observations.
- **Sharpe** = `(mean − rf/perYear)/std × √perYear`, only with ≥ 60 observations. `rf` = average €STR at the observation
  dates (`averageRate`: last rate on/before each date, dates without a rate skipped), only for EUR users; otherwise 0.
- **Sortino** = `(mean − rf/perYear) / downside × √perYear` with `downside = √(Σ min(0, r − rf/perYear)² / n)`
  (**n**, not n − 1); `null` with < 2 returns or zero downside.
- **Calmar** = `annualReturn / maxDrawdown` (drawdown as positive fraction); `null` unless drawdown > 0.
- **Historical VaR/CVaR**: sort ascending, `cut = max(1, floor(n·(1 − c)))`, `VaR = −sorted[cut−1]`,
  `CVaR = −mean(sorted[0..cut))`; `null` with < 100 returns.
- **Risk contributions** (Euler): Σ = sample covariance matrix; `marginal_i = Σ_j Σ_ij w_j`; `total = Σ_i w_i·marginal_i`;
  `share_i = w_i·marginal_i / total`; `null` with < 2 items, unequal lengths, < 60 observations or `total ≤ 0`.
- **Concentration**: weights clipped at 0 and normalised; `HHI = Σ w²`, `effectiveN = 1/HHI`.
- **Annualised return**: `(Π(1+r))^(perYear/n) − 1`, `null` if growth ≤ 0.

## 5. Drawdown — `computeDrawdown(baseKey, daily)`

On the TWR index (not on value, which jumps with deposits): `index *= 1 + ret`; when `index ≥ peak` the peak moves to
that day (and, if the worst drawdown so far started at the previous peak and is unrecovered, its `recoveryDate` is set
to this day). `drawdown = index/peak − 1`. `max` = the most negative point with its `peakDate`, `troughDate`,
`recoveryDate` (null if not recovered) and `current` = last drawdown. For `1anno`/`max` the chart uses one point per
month = the month's minimum (`monthlyMinimum`), then `samplePeriodSeries`.

## 6. Benchmark relation (inside `computePortfolioRisk`)

For each portfolio observation date: benchmark return = `price(date)/price(date − 1 calendar day) − 1` using the last
available price in user currency on/before each date; pairs need both prices and previous > 0. Benchmark volatility needs
≥ 20 pairs, beta/correlation ≥ 60 pairs, and the block is computed only when the portfolio has ≥ 20 observations.

## 7. Correlation matrix

Instruments: open positions with a positive value, in summary row order (value desc), first 8. Prices: provider/manual
closes only (`origin ≠ "operazione"`), in user currency, from the last close **before** `fromKey` up to today.
`pairCorrelation(a, b)`: returns only between consecutive **common** dates of both series; ≥ 20 return pairs else `null`.
Diagonal = 1; symmetric.

## 8. Title statistics — `computeTitleStats(closes, today)`

`closes` ascending. `dayChange = last/previous − 1`. Period change = `last/start − 1` where `start` = last close on/before
`last.date − PERIOD_DAYS` (YTD: on/before 31/12 of previous year of **`today`**), omitted when the start close is older
than 10 days before the target or ≤ 0. Year window = closes with `date ≥ last.date − 365 days`: `high52`, `low52`,
`fromHigh = last/high52 − 1`. If the window has **> 20** closes: daily close-to-close returns, `perYear` from
`observationsPerYear(n, daysBetween(firstWindow, lastWindow))`, volatility = `std × √perYear`, `maxDrawdown` = min of
`close/runningPeak − 1`. Date shifts are UTC (`toISOString`). `downsampleCloses(points, max)`: indices
`round(i × (n−1)/(max−1))` (JS `Math.round`: halves round toward +∞).
